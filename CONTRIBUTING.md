# Contributing to Bifrost Terminal

Bifrost Terminal is a personal fork of [Wave Terminal](https://github.com/wavetermdev/waveterm), maintained by heinsutton. It is not affiliated with Command Line Inc.

## Issues and pull requests

- Issues and pull requests on [this fork](https://github.com/heinsutton/bifrost-terminal) are welcome.
- For anything beyond a small fix, open an issue first so we can agree on direction.
- Keep each pull request to one logical change, and only change what the goal needs.
- Follow existing formatting and style. Use gofmt and prettier where applicable, and American English.

## Upstream

Changes that belong in Wave Terminal itself, and bugs that are not specific to Bifrost, should go to [wavetermdev/waveterm](https://github.com/wavetermdev/waveterm). Upstream has its own contribution process, which does not apply here.
